# Изменения 2.1

- Мульти-поиск: Gutendex / Project Gutenberg, Open Library, Google Books, Internet Archive и русская Викитека.
- Добавлены источники и внешние ссылки в карточки книг.
- Поиск на русском и английском с вариантами названий и транслитерацией.
- Жанровые запросы направляются также в дополнительные каталоги.
- Пустой запрос для «Книги дня» просматривает каталоги, а не только Gutenberg.
- Кэширует записи дополнительных источников для открытия избранного после перезапуска.
- Исправлено сохранение отрицательных Open Library ID в кэше.
- SQLite-соединения теперь гарантированно закрываются после операций.
- Добавлены регрессионные тесты.
- Прямые файлы показываются только если источник действительно вернул ссылку.
