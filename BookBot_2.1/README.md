# Book Bot 2.1 — расширенный каталог

Telegram-бот для поиска книг по нескольким открытым каталогам. Проект рассчитан на запуск в PyCharm.

## Источники

1. **Project Gutenberg (Gutendex)** — основной источник книг общественного достояния; если каталог предоставляет EPUB/PDF/FB2, бот может отправить файл в Telegram.
2. **Open Library** — международный и русскоязычный библиографический каталог: названия, авторы, годы, обложки, темы и описания. Сам по себе результат Open Library не означает, что файл можно скачать.
3. **Google Books API** — дополнительный международный поиск и метаданные. Кнопка скачивания появляется только если API возвращает `downloadLink` для EPUB/PDF.
4. **Internet Archive** — дополнительный поиск по цифровым коллекциям и ссылка на страницу экземпляра. В этой версии бот не скачивает файлы Archive автоматически: права, доступность и ограничения заимствования зависят от конкретного экземпляра и страны.
5. **Русская Викитека** — дополнительный поиск по русскоязычным произведениям; бот показывает страницу произведения на сайте. Это источник чтения/перехода, а не гарантированный EPUB/PDF.

Источники опрашиваются независимо. Если один каталог временно не отвечает, результаты остальных всё равно показываются. В выдаче одинаковые записи по возможности объединяются.

## Что изменилось

- Добавлены Open Library, Google Books, Internet Archive и русская Викитека как поисковые источники.
- По русским запросам используются исходное название, английские варианты и транслитерация.
- В карточке показывается название источника и кнопка **«Открыть источник»**.
- Кнопки скачивания показываются только для реально предоставленных прямых ссылок EPUB/PDF/FB2.
- Записи из новых источников сохраняются в `catalog_cache.json`, чтобы карточки из избранного открывались после перезапуска.
- Сохранены SQLite, избранное, история, жанры, книга дня, RU/EN интерфейс и пагинация.
- Исправлено закрытие SQLite-соединений и сохранение записей Open Library в кэше.

## Установка в PyCharm (Windows)

1. Распакуй ZIP в отдельную папку.
2. Открой в PyCharm папку проекта через **File → Open**.
3. Создай виртуальное окружение (PyCharm обычно предложит это автоматически).
4. Открой Terminal в PyCharm и выполни:

   ```bash
   python -m pip install -r requirements.txt
   ```

5. Скопируй `.env.example` в файл `.env`.
6. В `.env` вставь токен своего Telegram-бота:

   ```env
   BOT_TOKEN=твой_токен_от_BotFather
   ```

7. Запусти `bot.py` кнопкой Run или командой:

   ```bash
   python bot.py
   ```

Файл `.env` в ZIP намеренно отсутствует: токен должен оставаться только у тебя.

## Файлы проекта

- `bot.py` — Telegram-обработчики, карточки и интерфейс.
- `catalog.py` — поиск по источникам, карточки, доступные форматы и кэш.
- `query_language.py` — русские названия, английские варианты и транслитерация.
- `storage.py` — SQLite: избранное, история и язык.
- `requirements.txt` — зависимости.
- `.env.example` — пример конфигурации.
- `catalog_cache.json` — создаётся автоматически после поиска.
- `books.sqlite3` — создаётся автоматически при первом запуске.

## Важные замечания

- Число результатов в шапке — приблизительное: каталоги могут учитывать одни и те же произведения несколько раз.
- Наличие книги в поиске не означает наличие бесплатного файла. Open Library и Google Books в основном расширяют обнаружение; Gutenberg предоставляет прямые файлы для части коллекции.
- Интернет-архив может показывать книги с ограниченным доступом/заимствованием. Бот не обходит эти ограничения.
- Авторские права и доступность различаются по странам. Используй скачивание только там, где это разрешено.
- Open Library просит не использовать API для массового сбора данных и рекомендует указывать идентифицирующий User-Agent и контакт разработчика. Перед публичным развёртыванием замени `contact: configure-your-email` в `catalog.py` на свой контакт.
- Для стабильного доступа к API не запускай много копий бота одновременно.

## Проверка кода

В проект добавлены регрессионные тесты. Их можно запустить из терминала PyCharm:

```bash
python -m unittest discover -s tests -v
```

Тесты проверяют обработку запросов Internet Archive, объединение и дедупликацию результатов, русские варианты поиска, пространства ID, сохранение кэша и работу SQLite.

## Быстрая проверка

После запуска:
- `/start` — главное меню;
- `/help` — помощь;
- попробуй `Pride and Prejudice`, `Frankenstein`, `Война и мир`, `Достоевский`, `Евгений Онегин`, `Анна Каренина`;
- открой карточку: проверь источник, обложку, аннотацию и доступные форматы.

Не все перечисленные тестовые запросы обязаны возвращать скачиваемый файл: они проверяют именно расширенный поиск.
